# Appunti Universitari di Informatica — Università di Pisa

Raccolta personale di appunti, dispense e materiale di studio relativo al corso di laurea in Informatica presso l'Università di Pisa.

## Contenuti

- **[Primo anno](./01-primo-anno/)** — Laboratorio 1, Programmazione e Algoritmica.
- **[Secondo anno](./02-secondo-anno/)** — Architetture e Sistemi Operativi, Laboratorio 2, Ricerca Operativa.
- **[Terzo anno](./03-terzo-anno/)** — Basi di Dati, Ingegneria del Software, Reti e Laboratorio 3.
- **[Complementari](./99-complementari/)** — Crittografia, Paradigmi di Programmazione, Sicurezza ICT, Sviluppo Web e Mobile, Web Scraping.

## Struttura

Il materiale è organizzato per anno di corso e insegnamento. La sezione *Complementari* raccoglie argomenti aggiuntivi e approfondimenti.
