- **[Terzo anno](./03-terzo-anno/)** — Basi di Dati(non completo), Ingegneria del Software(non completo), Reti e Laboratorio 3(non completo).
- **[Complementari](./99-complementari/)** — Crittografia(non completo), Paradigmi di Programmazione, Sicurezza ICT, Sviluppo Web e Mobile, Web Scraping(non completo).
